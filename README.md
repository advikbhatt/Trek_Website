# Trek Website UI

This is a simple **Trek Display Website UI** built using **HTML**, **CSS**, and **JavaScript**. It allows users to explore trekking destinations.

## Features
- **Responsive Design**: Optimized for mobile, tablet, and desktop.
- **Smooth Navigation**: Easy-to-use navigation menu.
- **Image Gallery**: View trekking photos.

## Technologies Used
- **HTML**: Structure of the website.
- **CSS**: Styling and layout.
- **JavaScript**: Interactive features (e.g., form validation, image gallery).

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/your-repo/trek-website-ui.git
   ```
2. Open index.html in a browser to view the website.
